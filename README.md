## 📌 Overview

 

This responsive resume website was developed using semantic HTML and custom CSS. The layout and visual design strictly follow the Figma prototype provided by CodeSpace Academy. Each section has been carefully styled to reflect pixel-perfect spacing, colour schemes, and typography standards.

 

---

 

## ✨ Features

 

- ✅ Semantic and accessible HTML structure 

- ✅ Fully responsive across mobile, tablet, and desktop 

- ✅ Proficiency bars with dynamic widths 

- ✅ Skills displayed as visually styled badges 

- ✅ Projects and experience displayed using clean card layouts 

- ✅ Education section with date ranges and key learnings 

- ✅ Tools section grouped by category and displayed with icons 

- ✅ Contact section with live email, phone, GitHub, and LinkedIn links 

- ✅ Organized codebase with modular, reusable styles

 

---

 

## 🛠️ Technologies Used

 

- **HTML5** – Semantic structure 

- **CSS3** – Custom styling, Flexbox, Grid, media queries 

- **Google Fonts** – Poppins 

- **Icons** – Icons sourced from Icons8 and Devicon 

- *(No external frameworks like Tailwind or Bootstrap used — all custom CSS)*

## 🧪 Installation

 

1. Clone the repository:


   git clone https://github.com/VanessaDa/SDFPP-2025.git

 

2. Navigate to the project folder:

cd SDFPP-2025

3. Open the HTML file in your browser:

open index.html

 

No build tools or installations are required — just a modern browser.

 

📱 Responsiveness

The site is fully responsive:

Mobile: Stacks sections vertically, reduces font sizes, and simplifies layout
Tablet: Adjusts spacing and image sizes
Desktop: Full-width layout using Grid and Flexbox
Media queries are defined for:

@media (max-width: 768px) { ... }

@media (max-width: 640px) { ... }
